Privacy Policy for Sekant Web Security

Effective Date: 23 September 2026

Your privacy matters to us. This Privacy Policy explains how Sekant Web Security handles your information when you use our browser extension.

Managed vs Unmanaged Mode
Sekant Web Security can operate either in Unmanaged Mode (for Consumers) or Managed Mode (for Organizations).

  • Unmanaged Mode (Consumers): Installed by individual user. Operates solely under the user's control. Free to use.
  • Managed Mode (Organizations): Installed and configured by an organization to enforce security policies. Paid subscription.

What Data We Handle / Transmit
Sekant Web Security analyzes web content, clipboard content, and user interactions locally on your device to detect security risks. We do not share any information with advertisers or data brokers, nor do we process data for personalized advertising or other analytic purposes. The only third-party operational services used are external DNS (e.g., Cloudflare, Quad9) and WHOIS lookup APIs.

  • Unmanaged Mode (Consumers): Data is not transmitted to remote servers.
  • Managed Mode (Organizations): Data may be transmitted to the organization's servers for security policy enforcement.

User Control

  • Unmanaged Mode (Consumers): Users have full control over the extension, and can uninstall or disable at any time.
  • Managed Mode (Organizations): Control is determined by the organization's policies.

Local Storage
The extension stores configuration settings and personalization information locally in your browser. This data is used to customize your experience.

Third-Party Services
Sekant Web Security does not use any third-party tracking, analytics, or advertising services. Only DNS (Cloudflare, Quad9) and WHOIS lookup services are utilized.

Contact Us
If you have any questions or concerns about this privacy policy, please contact us at: support@sekantsecurity.com
